One original single-line joke about office life, written for the
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
on make.fun — the sort of line you send a colleague after a meeting that
should have been an email:

> Our trust fall exercise went well — HR caught the lawsuit, and I caught the floor.

The setup sounds like a wholesome team-building success story; the
punchline splits the fallout in two. HR gets the paperwork, the narrator
gets the floor.

## Run it

```sh
python3 main.py
# writes the joke to /output/entry.txt
```

Pure Python standard library, no dependencies. `main.py` validates the
line first (1–200 characters, single line, no control characters, no
leading or trailing space) and then writes it to `/output/entry.txt`.
